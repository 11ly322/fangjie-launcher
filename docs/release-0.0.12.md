## 修复与改进

- **手柄状态图标**：顶栏改为 34px 图标按钮，不再挤压“手柄”文字；图标的 SVG 尺寸和可点击区域固定。
- **空间焦点导航**：方向键/左摇杆按元素在屏幕上的相对位置寻找最近目标，不再只按 DOM 顺序移动；打开弹窗时，焦点限制在弹窗内。
- **连续移动**：按住方向键或摇杆先立即移动，短暂停顿后按固定间隔连续移动；切换方向时重新计算。
- **主页面切换**：LB/RB 在启动、下载、联机、设置之间切换，焦点自动落到当前主标签。
- **按键反馈**：A 确认当前焦点，B 关闭弹窗或返回上一级；焦点使用高对比描边与光晕，右下角显示操作提示。
- 空实例首页继续使用左右两栏布局，说明、按钮与右侧像素书架不会重叠。
