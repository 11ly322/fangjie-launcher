# UBL 0.0.141

发布日期：2026-11-01

0.0.141 是一次全界面手柄适配版本：所有页面、标签页和弹窗都支持手柄焦点导航、标签切换、滑杆/下拉调整和右摇杆滚动。不改变存档、实例或模组文件结构。

## 新增与改进

- **完整焦点引擎**：手柄可聚焦原生控件、`role=button`、`role=tab` 和自定义可聚焦卡片；隐藏、禁用、`aria-hidden` 或不可见控件自动跳过。
- **页面与标签**：LT/RT 切换主页面，LB/RB 在当前页面的标签组内循环；弹窗内 LB/RB 只切换弹窗标签，不会误切后台页面。
- **滑杆与下拉**：聚焦滑杆后用左右键按步长调整，A 也可增加；下拉框左右键循环选项并跳过禁用项。文本输入框可聚焦，输入仍使用实体键盘。
- **滚动与弹窗**：右摇杆滚动当前弹窗内容或主内容区；弹窗打开后焦点进入正文，关闭后回到打开前的控件；B 关闭弹窗不再丢失手柄焦点，打开动画期间也不会误触页面返回。
- **按键提示**：顶栏手柄状态与底部提示更新为方向键/左摇杆、A/B、LB/RB、LT/RT、右摇杆和 Start 的完整说明。

- 发布包未做代码签名，Windows SmartScreen 可能提示未知发布者。
