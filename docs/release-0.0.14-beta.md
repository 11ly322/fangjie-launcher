# UBL 0.0.14-beta

发布日期：2026-10-31

0.0.14-beta 是一次账号入口版本：把正版/离线切换放到主界面顶栏，切换离线时保留在线登录与已保存的 Microsoft 账号。不改变存档、实例或模组文件结构。

## 新增与改进

- **主界面账号切换**：顶栏新增“正版 / 离线”双按钮，可在当前页面直接切换账号类型，不必先打开账号弹窗。
- **保留在线登录**：切到离线只切换当前账号，不删除 Microsoft 账号、逐账号加密令牌或其他已保存账号；切回正版即可继续使用原登录。
- **多账号状态**：正版与离线账号列表、当前账号高亮、逐账号头像和令牌映射保持一致。
- **账号入口**：账号弹窗支持从顶栏直接打开对应分页；没有可用正版账号时引导添加。
