# 方界 0.0.2-beta

这是 `0.0.2-beta` 预发布版，重点是模组工坊的版本与前置管理。

## 新增

- **前置索引与跳转**：安装前展示必需/可选前置，点击即可打开对应项目详情。
- **模组版本选择**：在项目详情中选择具体版本，显示版本号、发布类型、日期与大小。
- **介绍页面跳转**：从安装弹窗直接打开 Modrinth/CurseForge 项目页。
- **CurseForge 模组源**：搜索、详情、依赖补齐与文件安装；资源包/光影同样支持双源。
- **安装版本切换**：已安装模组可切换版本，替换旧 JAR 并更新安装记录。

## 验证

- CurseForge Mouse Tweaks 从 2.25 切换到 2.26：旧 JAR 被替换，安装记录更新。
- 必需前置 Fabric API 在切换后仍然保留。
- Iris Shaders 的 Sodium 前置可从依赖索引直接跳转。
- 类型检查、单元测试与生产构建通过。

## 已知边界

- 安装包未做受信任代码签名；Windows SmartScreen 可能提示未知发布者。
- 真实签名 NSIS 自动替换与公开更新 feed 仍需实测。
- 跨机器 NAT 与 EasyTier P2P RTT 仍需实测；当前延迟为地址/中继 TCP。
- OptiFine 安装依赖本机 Java 和用户提供的官方 installer。
- 连接器为独立 GPL-3.0-or-later 组件；启动器主体 MIT。

## 校验

下载后请用 `SHA256SUMS.txt` 校验。发布页同时列出安装包与便携版的 SHA256。
