## 本次更新

- 设置页移除没有可见标题的兼容性开关；版本隔离改为带说明的完整设置项。
- 加载器下载从“新建实例”里独立出来，下载中心可直接选择游戏版本和可用加载器，只写入共享版本目录，不创建实例。
- 顶栏增加退出启动器按钮；模组工坊等二级页面增加返回/退出入口。
- 增加手柄导航：方向键/D-pad 移动焦点，A 确认，B 返回或关闭弹窗，支持连接状态提示。
- 账号入口支持正版/离线切换；可保存多个正版账号并热切换，切换后保留已登录令牌，离线档案不会清空正版账号。
- 设置页增加默认版本隔离策略：关闭、隔离可安装 Mod 的版本、隔离非正式版、隔离可安装 Mod 的版本与非正式版、隔离所有版本。只影响新建实例。
- 保留书架视觉、日夜模式、整合包下载、世界快照、模组更新中心和独立加载器管理。

## 验证

- `npm run typecheck`、`npm run build` 通过。
- `npm test -- --run`：21 个测试文件、68 个测试通过。
- 便携版启动 smoke、NSIS 静默安装/卸载、0.0.9 → 0.0.10-beta 安装目录与用户数据保留通过。
- 账号热切换、正版/离线入口、退出确认与模拟手柄焦点导航通过 Electron E2E。
- 独立加载器下载、加载器可用性过滤、模组工坊二级页面退出通过 Electron E2E。

## 边界

- 发布包未做代码签名，Windows SmartScreen 可能提示未知发布者；请校验 SHA256 后运行。
- 手柄验证使用 Gamepad API 模拟输入，未覆盖所有实体手柄型号。
- 0.0.8 及更早版本的内置更新助手无法自替换，需要手动安装一次 0.0.9 或更新的安装包；0.0.9 起更新助手已修复。
- 跨机器 NAT/P2P 延迟与真实签名自动更新仍建议按文档实测。
