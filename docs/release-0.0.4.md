# 方界 0.0.4

这是 `0.0.4` 预发布版，汇总已安装模组更新中心、实例/世界快照和启动器性能基础优化。

## 新增

### 模组更新中心

- 批量检查已安装模组的兼容更新，按“可更新 / 已是最新 / 不可自动更新”分组。
- 支持单个更新、全部更新、跳过此版本、固定/取消固定版本。
- 更新前把旧 JAR 备份到实例 `.fangjie/backups/mods/<时间戳>/`；失败自动回滚，成功后支持手动回滚。
- 展示新增/移除的必需前置；缺失前置在更新时自动补齐。
- 离线模式直接返回离线报告，不发起网络请求。

### 实例/世界快照

- 手动或启动前自动快照 `saves/`、`options.txt`、`config/`、模组清单和实例元数据。
- 流式 ZIP 写入，不把整个存档读入内存；自动快照保留最近 5 份。
- 恢复前展示创建/覆盖 diff，并自动生成安全快照；游戏运行时拒绝创建和恢复。
- 删除实例时可选择把快照迁移到 `<数据目录>/snapshots-archive/<实例id>/`。

### 性能基础

- 每实例 `.fangjie/mods-index.json`：按文件名、mtime、大小增量复用解析结果。
- `app:bootstrap` / `app:snapshot` 只返回实例摘要和 `modCount`；新增 `instances:detail` 按需加载完整实例。
- Modrinth / CurseForge 项目与版本元数据落盘缓存，带 TTL 和 ETag / `If-None-Match`。
- Java 检测按路径 + mtime 缓存；首屏返回缓存并后台刷新，设置页可强制重新检测。
- 下载任务事件全局 120 ms 合并，避免每个任务重复推送全量列表。

## 验证

- `npm run typecheck`、`npm test`（16 个文件 / 49 个测试）、`npm run build` 通过。
- 隔离 200 模组实例：冷启动到可交互 `2146 ms → 1487 ms`；`snapshot()` JSON `42,163 B → 992 B`；`instanceMods` 200 条 `66 ms → 15 ms`；重复详情页 API 请求 `1 → 0`。
- 真实 Fabric 1.20.1 实例：更新 Fabric API 后旧 JAR 不残留，手动回滚恢复旧 JAR；删除 Sodium 后更新 Iris 会自动补齐前置。
- 快照：创建、预览 3 项覆盖、恢复和安全快照通过；503 MB 存档快照主进程峰值内存约 229 MB；删除实例并保留快照归档通过。
- `0.0.4` 便携版启动、NSIS 静默安装/卸载和产品版本检查通过。

## 升级提示

`0.0.3` 及更早版本可在更新检查中获取本版；安装前请备份重要存档。更新器仍会校验安装包 SHA256。

## 已知边界

- 安装包仍未使用受信任证书签名，Windows SmartScreen 可能提示未知发布者。
- 真实签名 NSIS 自动替换、跨机器 NAT 与 EasyTier P2P RTT 仍需按文档实测。
- 快照恢复只覆盖快照内文件，不删除快照外新增文件；自动快照不包含 `mods/` 目录本身，只记录模组清单。
- 离线“零请求”由服务层短路和单元测试保证，未做系统级抓包。
- 连接器为独立 GPL-3.0-or-later 组件；启动器主体 MIT。
