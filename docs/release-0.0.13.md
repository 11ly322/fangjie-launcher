## 修复与改进

- **更新下载进度**：更新面板显示已下载大小、总大小和百分比，不再只显示旋转图标。
- **卡住自动重试**：连续 45 秒没有收到新数据时中断当前下载并自动重试一次，避免连接静默挂起后无限等待。
- **浏览器下载兜底**：更新面板提供“浏览器下载”和发布页入口；直连失败时仍可手动获取安装包。
- **外部链接限制**：只允许打开本项目 GitHub 发布相关地址，拒绝其它协议或站点。
