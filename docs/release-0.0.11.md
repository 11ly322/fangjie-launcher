# UBL 0.0.11

发布日期：2026-10-31

0.0.11 是一次界面与手柄操作修复版本，不改变存档、实例或模组文件结构。

## 修复

- 空实例首页改为明确的两栏布局：左侧说明与操作按钮，右侧像素书架，中间由分隔线隔开。书架不再使用绝对定位覆盖内容，窗口变窄时会自动上下排列，手机宽度下隐藏书架装饰。
- 手柄导航增加可见焦点环、当前选项滚动到可见区域和底部按键提示；连接手柄后顶栏显示状态，方向键或左摇杆切换焦点，A 确认，B 返回或关闭弹窗。
- 手柄初始焦点落在主导航当前标签，窗口标题栏按钮不再参与手柄导航。

## 验证

- `npm run typecheck`、`npm run build`、`npm run package:installer` 通过。
- `npm test -- --run`：21 个测试文件、68 个测试通过。
- 打包便携版 smoke：标题、桥接、顶栏和版本 `v0.0.11` 正常。
- NSIS 静默安装/卸载：文件与产品版本 0.0.11，卸载后目录清理。
- 0.0.10-beta → 0.0.11 覆盖安装：安装目录哨兵文件保留，版本更新到 0.0.11。
- Electron E2E：空实例首页两栏边界无重叠；模拟手柄连接后焦点环出现，方向键从“启动”移动到“下载”，A 打开下载页，B 返回首页并关闭弹窗。

## 边界

- 发布包未做代码签名。
- 手柄测试使用模拟 Gamepad API 与虚拟按键，未覆盖所有实体手柄型号。
- 0.0.8 及更早版本的更新器仍有旧替换缺陷，需要手动安装一次 0.0.9 或更新版本。
