# UBL 0.0.5

发布日期：2026-10-31

`unflod bindery launcher`（UBL）是原“方界启动器”的 0.0.5 版本。首发包含品牌更名、书架主体的扁平化界面、日夜模式、智能加载器筛选、手动版本筛选、独立下载与更完整的中文搜索/筛选。旧版实例与 `%APPDATA%\fangjie-launcher` 数据目录继续复用，升级不会迁移或删除已有数据。

## 主要变化

- **更名与品牌**：窗口标题、侧栏、启动画面、安装包、便携版可执行文件、快捷方式与发布资产统一为 `unflod bindery launcher` / `UBL`；内部包名与数据目录保留兼容。
- **书架 UI**：首页、实例详情与侧栏加入书架/书脊语言，新增低 bit 像素书架插画；界面改为扁平、仿 iOS 的卡片、胶囊按钮与半透明面板。
- **日夜模式**：苔原、深海、余烬三套配色分别提供黑夜/白天模式，切换立即生效并持久化。
- **智能加载器**：创建实例时按 Minecraft 版本核验 Fabric/Quilt/Forge/NeoForge 元数据，只显示有可下载版本的加载器；离线时不发请求。
- **独立下载**：模组详情“仅下载文件”保存到 `<数据目录>/downloads/mods/`；创建实例弹窗“仅安装加载器”把加载器写入共享游戏目录，不创建实例。
- **筛选增强**：模组游戏版本支持手动输入；分类扩展到 16 类；保留中文搜索转换、版本/加载器/运行环境筛选。
- **既有能力**：模组更新中心、世界快照、中文搜索、双模组源、资源包/光影、OptiFine、房间联机、崩溃诊断与性能缓存继续保留。

## 验证

- `npm run typecheck`、`npm test`（17 个文件 / 54 个测试）、`npm run build`、`npm run package:installer` 通过。
- 便携版打包后启动验证：标题 `unflod bindery launcher`，bridge 与 `.app-shell` 正常，版本显示 `0.0.5`。
- NSIS 静默安装/卸载验证：安装目录、`UBL.exe`、Rust sidecar、DisplayVersion `0.0.5` 与卸载清理均通过。
- 加载器可用性实测：Minecraft 1.7.10 仅 Forge 有版本，弹窗只显示 Forge 与原版；1.20.1 显示四个加载器。
- 独立模组下载实测：Sodium 保存为 `downloads/mods/sodium-fabric-0.5.13+mc1.20.1.jar` 并创建下载任务。
- 界面实测：黑夜/白天、三套配色、低 bit 像素书架、创建实例与模组工坊页面在真实 Electron 渲染中检查。

## 已知边界

- 仍然只面向 Windows 10/11 x64，发布包未做代码签名，SmartScreen 可能提示未知发布者。
- 独立加载器安装未做完整真实下载 E2E；首次使用会按所选版本拉取加载器及其依赖。
- 中文翻译是本地词典与术语替换，不是通用机器翻译；未覆盖文本保留英文。
- CurseForge 不支持运行环境筛选；真实签名自动更新与跨机器 NAT 仍需实测。
- 房间联机依赖公共中继，不保证所有网络环境可直连；请先备份重要存档。
