# UBL 0.0.15

发布日期：2026-11-02

0.0.15 是一次数据目录恢复版本：修复自定义数据目录所在磁盘离线时，启动器在窗口出现前抛错、进程占用单实例锁却不显示界面的问题。不改变存档、实例或模组文件结构。

## 修复

- **启动不再无窗口卡死**：启动器在创建窗口前校验已保存的数据目录。磁盘未连接、路径中包含同名文件或没有写入权限时，保留原设置，临时回退到默认数据目录并记录原因，不再让初始化异常中断窗口创建。
- **可见提示**：回退时主界面顶部显示“数据目录已临时切换”，列出原目录、本次回退目录和恢复方式，并提供“数据设置”入口。原数据目录指针不会被改写。
- **启动失败兜底**：初始化仍失败时写入 `launcher-main.log`、弹出错误框并退出，不再留下没有窗口却占用单实例锁的后台进程。
- **可读错误原因**：将 `ENOENT`、`ENOTDIR`、`EACCES` 等系统错误转换为中文原因。

## 边界

- 发布包未做代码签名，Windows SmartScreen 可能提示未知发布者。
- 0.0.141 的版本号数值大于 0.0.15，内置更新器不会把 0.0.15 识别为更新；需要此修复的用户请从发布页手动下载 0.0.15 覆盖安装。0.0.15 之后的版本继续按递增版本号发布。
- 数据目录回退只保证启动器可用；原目录中的世界、模组和配置不会复制到回退目录，磁盘恢复后重启仍使用原目录。
